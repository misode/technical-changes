pack breaking | Data pack format has been increased to `122.0`.

pack breaking | Resource pack format has been increased to `98.0`.

network | Added C2S packet `mod_list`, which empty in vanilla but allowed modded platforms to send information to the server.

network | Modified C2S packet `intention`. Modified the format of the `host` field.

network | Modified S2C packet `transfer`. Added field `properties`.

options | Added `allowed-connection-ids` option to the `server.properties` file, which is a list of comma-separated IDs.

options | Added `status-contact-details` option to the `server.properties` file. Meant as a human-readable value which will be sent in the `status_response` packet JSON payload under the `contact` property.

options | Added `enable-legacy-status` option to the `server.properties` file. Defaults to `true`.

debug | Removed debug properties `-DMC_DEBUG_ORE_VEINS`, `-DMC_DEBUG_AQUIFERS`, and `-DMC_DEBUG_DISABLE_ORE_VEINS`.

command breaking | The `/fillbiome` command will now fill biomes with block accuracy.

worldgen | Changed tree feature trunk placer `straight_trunk_placer`: added `trunk_width` field, which is an int provider defaulting to `1`.

worldgen breaking | The domain in the XZ plane of placed features is now validated. Feature placement can only occur within a 3x3 chunk region: as such, it is not valid for a placed feature to select a position outside that range.

worldgen breaking | Changed placement modifier `cuboid`: `xz_size` and `y_size` have been adjusted to represent the actual size of the cuboid, instead of implicitly being 1 block larger. For example `xz_size` of `2` will produce a 2x2 cuboid instead of 3x3.

worldgen breaking | Changed placement modifier `fixed_placement`: `positions` now requires at least one element.

worldgen breaking | Changed noise settings. Removed field `default_block`, this is now always `air`, any other block should be defined by the material rule.

worldgen | Changed behavior of material condition `steep`. No longer considers height modifications from eroded badlands surface extensions in an order-dependent way.

tag | Aded biome tags `#generated_in_below_zero_retrogen` and `#is_cave`.

assets shader | Simplified the OIT (Order-Independent Transparency) shader by replacing the wavelet-based mathematics with depth bin-based accumulation.
* Slightly improved performance at least on some devices
* Reduced floating point precision issues on average
* `OIT_WAVELET_RANK` shader define was removed
* `OIT_COEFF_COUNT` shader define was replaced by OIT_NUMBER_OF_DEPTH_BINS
* `OIT_COEFF_ATTACHMENT_COUNT` shader define was renamed to `OIT_TRANSMITTANCE_TARGET_COUNT`
