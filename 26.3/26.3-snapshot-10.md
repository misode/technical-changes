command component | Re-added the `none` swing animation type to the `/swing` command and the `attack_animation` and `interact_animation` data components.

command | Added `/compute` command which evaluates number providers, with contexts `origin` and `this`. Syntax `/compute <target> <provider> [<scale>|integer]`, with:
* `<target>`: one of `default`, `block <pos>`, or `entity <selector>`.
* `<provider>`: a number provider ID or inline value.
* `<scale>`: optional scale value to multiply the final result.

command | Added new source to `/data modify` command: `compute`, with syntax `compute <target> <provider> [integer]` working the same as in `/compute`.

item component | Changed data component `block_transformer`: contents have been moved to a separate registry. Component must now always refer to a `block_transformer` file instead of an inline definition.

item component | Changed data components `attack_animation` and `interact_animation`: `duration field is now a non-negative integer.
