pack breaking obsolete | Data pack format has been increased to `128.0`.

pack breaking | Resource pack format has been increased to `104.0`.

options | Added `key-rotation-period-seconds` to `server.properties`. It specifies the minimum time before server connection keys are recreated and defaults to `60`. `0` creates a unique ephemeral key for every connection.

command | Added support for local 2D coordinates in the form `^<left> ^<forwards>` in `/forceload`, `/spreadplayers`, and `/worldborder center`. Rotation is interpreted around the Y axis.

dispense-behavior | Added the `dispense_behavior` registry and folder for data-driven dispenser behavior sequences. Registry entries contain behavior entries with a `type` and type-specific fields. Added dispense behavior types:
* `brush_armadillo`
* `charge_respawn_anchor`
* `convert_to_mud`
* `drop_item`
* `empty_bucket`
* `equip`
* `equip_chest`
* `equip_sulfur_cube`
* `fill_bottle`
* `fill_bucket`
* `grow_plant`
* `ignite`
* `insert_into_container`
* `place_armor_stand`
* `place_block`
* `place_boat`
* `place_minecart`
* `shear`
* `spawn_golem_from_carved_pumpkin`
* `spawn_mob`
* `spawn_tnt`
* `spawn_wither_from_wither_skeleton_skull`
* `transform_block`

component | Added data component `dispense_behavior`, whose value is a `dispense_behavior` registry entry ID or an inline list of dispense behaviors.

component nbt entity | Boat and minecart items now include the `entity_data` component by default. Dispensing or using the item fails if the entity type does not match the item behavior's requirements.

block-transformer | Added block transformer `honeycomb`, used to wax blocks from dispensers.

particle breaking | The `current_down` particle now has a `radius` field for the radius around the position in which particles spawn.

particle | The `bubble_column_up` particle now has an optional `pop_chance` field between `0.0` and `1.0`, defaulting to `0.0`.

dialog | Dialog inputs now show red text and a warning tooltip when they appear to contain an email address.

lang assets breaking | Resource packs can no longer replace language keys beginning with `menu.custom_options` or `menu.custom_screen_info`.

shader | Updated `core/terrain.fsh` to support the separate improved fog setting.
