data | Added optional `location_based_effects` to sulfur cube archetypes. Each entry has the same format as a location-based enchantment effect, and level-based values are always evaluated with level `1`.

worldgen density | Changed density function `gradient`. The `from_coordinate` and `to_coordinate` fields now accept vertical anchors when `axis` is `y`.

worldgen density | Added density function `domain_warp`, which applies coordinate offsets to an input density function. It has optional `offset_x`, `offset_y`, and `offset_z` density functions, defaulting to `0.0`, and at least one offset must be specified.

worldgen structure | Added optional `corner_constraint` to structure pool elements. It is a list of constraints containing `density_function`, `acceptable_density`, optional `padding` (integer from `0` to `8`, defaulting to `0`), optional `corners` (`all`, `top`, or `bottom`, defaulting to `all`), and `required_corners`.
