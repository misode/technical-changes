pack breaking obsolete | Data pack format has been increased to `110.0`.

pack breaking obsolete | Resource pack format has been increased to `91.0`.

command | Added command `/posteffect`, which allows adding or removing post effects to players. Syntax:
* `/posteffect add <player> <posteffect>`
* `/posteffect clear <player>`
* `/posteffect list <target>`
* `/posteffect remove <player> <posteffect>`

command | The `/place feature` command now allows inline feature definitions.

environment-attribute breaking | Changed environment attribute `gameplay/bed_rule`:
* Renamed field `explodes` -> `destroy_on_use`.
* Added `destroy_on_leave`, an optional boolean.

environment-attribute | Added environment attribute `gameplay/straw_bed_rule`, with the same format as `gameplay/bed_rule`.

item component | Changed format of data component `block_transformer`: added optional boolean `update_from_neighbors`, whether the transformed block should update based on neighboring blocks, defaults to `true`.

item component | Added data component `compostable`, with field `layers`: namespaced ID to a number provider.

loot predicate data | Vanilla loot tables now reference predicates for checking if a tool has silk touch and is shears instead of inlining a copy of those checks. Added vanilla predicates: `tool/can_silk_touch`, `tool/can_shear`

item component breaking | Changed data component predicate `potion_contents`. Its format is now an object with optional fields:
* `potions`: potions to match (same as previous format).
* `effects`: collection predicate of mob effect predicates.

number-provider | Number providers can now be defined as data pack files in the folder `number_provider`.

number-provider | Added number provider `number_dispatcher`, which has fields `cases` (list of object with `condition` predicate and `number_provider`), and `default` number provider.

number-provider | Added number provider `conditional_value`, which has fields `condition` (predicate), `on_true` (number provider), and `on_false` (number provider).

number-provider | Added number provider `weighted_list`, with field `distribution` (weighted list of number providers).

recipe | Added recipe type `brewing` controlling brewing stand recipes. With fields:
* `input`: ingredient with required field `item` and optional field `potion_contents` (the 3 items you put at the bottom of the brewing stand).
* `reagent`: ingredient with required field `item` and optional field `potion_contents` (the item you put at the top of the brewing stand).
* `output`: item stack of the resulting item.

worldgen breaking | Removed feature types `coral_mushroom`, `kelp`, `seagrass`, and `sea_pickle`. They can be implemented with other more configurable feature types.

worldgen breaking | Changed feature types `coral_claw` and `coral_tree`: added required field `feature`, which is a placed feature placed.

worldgen | Added placement modifier `cuboid`, which repeats a feature in a cuboid shape. It has fields `xz_size` (int provider between 1 and 16), `y_size` (int provider between 1 and 16), `include_interior` (optional boolean), and `include_edges` (optional boolean).

worldgen | Added placement modifier `random_chance`, with field `chance` (float between 0 and 1).

worldgen | Changed block state provider `copy_properties_provider`: renamed `source_block_state_provider` -> `source`.

worldgen | Added block state provider `random_block_provider`, with field `blocks` (block ID, list of block IDs, or block tag).

worldgen | Changed `rotated_block_provider`. Now works on any block with `axis` or `facing` properties. Changed fields:
* Changed `state`: now a block state provider instead of a block state.
* Added optional `direction`, if omitted, a random direction is chose.

worldgen | Added rule test `any_of`, with field `rules`.

worldgen | Added rule test `not`, with field `rule`.

tag | Added block tags `#sculk_growth_inhibitors`, `#cats_can_sit_on`, `#cats_can_lie_on`, `#speeds_up_zombie_villager_curing`, `#villagers_can_sleep_on_bed`, `#villager_babies_can_jump_on_bed`, `#height_specific_ore_replaceables`.

tag | Renamed item tag `#dowses_campfires` -> `#douses_campfires`.

tag | Added structure tag `#abandoned_camp`.

assets breaking | Removed `shade` from block model elements. Replaced with optional field `shade_direction_override` (direction).

assets shader | Resource pack can now define always-on `minecraft:end_of_frame` post effect, which will be applied before any other post effect.
