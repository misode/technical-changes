pack breaking obsolete | Data pack format has been increased to `115.0` (skipping `114.0`).

pack breaking obsolete | Resource pack format has been increased to `95.0`.

block blockstate nbt breaking | Changed format of block states:
* Renamed `Name` -> `id`
* Renamed `Properties` -> `properties`
* The default block state of a block can now also be referred to in a compact form directly by the block ID.

command | Changed the `/swing` command:
* When used on a player, the player's attack strength will no longer be reset.
* Added optional argument to set the swing animation to play, one of `whack`, `stab`, defaults to `whack`.
* Added optional argument to set the duration of the swing animation, defaults to `6t`.

item component breaking | Removed data component `swing_animation`. Replaced with data components `attack_animation` and `interact_animation`: object with fields `type` (one of `whack`, `stab`) and `duration` (positive integer in ticks).

item component breaking | Removed data component `map_color`, since maps are no longer drawn as a tinted overlay.

loot item-modifier breaking | Changed loot function `exploration_map`:
* Removed field `map_color`.
* No longer changes the item ID from `map` to `filled_map`, instead `filled_map` should now be specified in the loot entry or villager trade itself.
* If no matching structure is found, the item is left without `map_id` component, use `filtered` with `discard_item` to drop those.

worldgen density breaking | Density functions and noises are no longer evaluated with double-precision floating point values, but instead with single-precision. This affects all intermediate steps, not just the final result.

tag | Added block tags `#concrete_stairs` and `#concrete_slabs`.

tag | Added item tags `#concrete_stairs`, `#concrete_slabs`, `#cloneable_maps`, and `#extendable_maps`.

assets breaking | Removed texture `item/filled_map_markings.png`.

assets item breaking | Removed item model tint source `map_color`, since the data component no longer exists.
