pack obsolete breaking | Resource pack format has been increased to `86.2`.

scoreboard | A player's score will no longer be displayed in the player tab overlay if the player doesn't have the objective.

network | Minecraft Server Management Protocol version has been increased to `3.0.0`.

network | The management server now starts before the Minecraft server starts. This means the heartbeat will be sent while the world is loading.

network | The `rpc.discover` and `notification/server/status` methods are now accessible before the dedicated server spins up.

data obsolete | Entries in the `sulfur_cube_archetype` registry have a new optional field `explosion_fuse`.

particle | Added `geyser`, `geyser_poof`, `geyser_base`, and `geyser_plume` particles.

command breaking | Team color arguments now accept only lowercase names with underscores.

attribute breaking | Renamed `nameplate_distance` attribute to `name_tag_distance`.

worldgen | Added `matching_biomes` block predicate type for world generation, which checks if the block position matches one of the specified biomes.

worldgen breaking | The `below_trunk_provider` block state provider in `tree` feature configuration no longer has a default value.

worldgen breaking | Field `block` of configured feature `multiface_growth` is now mandatory (defaulted to `grow_lichen`).

worldgen | Added `interval_select` density function, which selects between a number of density functions based on an input density function and a set of threshold values.

worldgen breaking | Removed `weird_scaled_sampler` density function. Its functionality has been replaced by `interval_select`.

tag block | Added several block tags for blocks which some mobs are immune to. These have effect on dismounting and valid surroundings of spawn placements for some mobs.

particle | Added `geyser_base` particle, which spawns as a cloud on the base of an erupting Potent Sulfur block.

particle | Added `geyser_poof` particle, which spawns as a cloud on the base of an erupting Potent Sulfur block.

particle | Added `geyser_plume` particle, which spawns as an upwards stream above an erupting Potent Sulfur block.

particle | Added `geyser` emitter particle, which spawns the `geyser_base`, `geyser_poof`, and `geyser_plume` particles above an erupting Potent Sulfur block.

game-test | Added `difficulty` game test environment, which sets the difficulty of the game test environment.

assets sound | Added sounds for Geyser eruptions: `block.potent_sulfur.geyser_eruption` and `block.potent_sulfur.geyser_eruption_active`.

assets particle | Added new `geyser_base`, `geyser_poof` and `geyser_plume` particle textures.
