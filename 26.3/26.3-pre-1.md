pack breaking obsolete | Data pack format has been increased to `119.0`.

pack breaking | Resource pack format has been increased to `97.1`.

number-provider breaking | Split the `number_provider` registry into `context_int_provider` and `context_float_provider` to avoid accidental loss of precision due to mixing of float and integer operations.

number-provider breaking | Split some number providers into both context int and context float provider:
* `constant`
* `uniform`
* `storage`
* `add` (renamed from `sum`)
* `mul` (renamed from `product`)
* `min` (renamed from `minimum`)
* `max` (renamed from `maximum`)
* `avg` (renamed from `average`)
* `weighted_list`
* `conditional`
* `number_dispatcher`
* `environment_attribute`

number-provider breaking | Moved some number providers only to context int providers:
* `binomial`
* `score`

number-provider breaking | Moved number provider `enchantment_level` only to context float provider.

number-provider | Added new context int provider types:
* `abs` with field `input`.
* `from_float` with field `input`.
* `mod` with fields `left` and `right`.
* `floor_mod` with fields `left` and `right`.
* `environment_attribute` with field `attribute` (unusable because there are no integer environment attributes).
* `negate` with field `input`.
* `pow` with fields `base` and `exponent`.
* `div` with fields `left` and `right`.
* `floor_div` with fields `left` and `right`.
* `sub` with fields `left` and `right`.

number-provider | Added new context float provider types:
* `abs` with field `input`.
* `ceil` with field `input`.
* `cos` with field `input`.
* `sub` with fields `left` and `right`.
* `floor` with field `input`.
* `from_int` with field `input`.
* `length` with field `inputs`.
* `mod` with fields `left` and `right`.
* `negate` with field `input`.
* `pow` with fields `base` and `exponent`.
* `div` with fields `left` and `right`.
* `round` with field `input`.
* `sin` with field `input`.
* `sqrt` with field `input`.
* `truncate` with field `input`.

command | Changed `/compute` command to take into account number provider split. Syntax is now:
* `/compute <target> integer <context_int_provider>`
* `/compute <target> float <context_float_provider> [<scale>]`

command | Changed `/data ... compute` command. Syntax is now:
* `... compute <target> integer <context_int_provider>`
* `... compute <target> float <context_float_provider>`

loot predicate breaking | Removed loot condition `value_check` and replaced with `int_value_check` and `float_value_check`, both with fields `value` and `test`.

recipe breaking | The `cookingtime` field in all cooking recipes is no longer optional. For smokers and blast furnace this value should be twice the previous value, because speedup is handled by the `cooking_fuel` component. If field was missing, should be set to `200`.

worldgen | Block state providers can now be defined as data pack files in the `worldgen/block_state_provider` folder. An inline block state is now also an accepted shorthand form.

worldgen breaking | Renamed block state providers:
* `copy_properties_provider` -> `copy_properties`.
* `dual_noise_provider` -> `dual_noise`.
* `noise_provider` -> `noise`.
* `noise_threshold_provider` -> `noise_threshold`.
* `randomized_int_state_provider` -> `randomized_int`.
* `rule_based_state_provider` -> `rule_based`.
* `simple_state_provider` -> `simple`.
* `weighted_state_provider` -> `weighted`.
* `random_block_provider` -> `random_block`.
* `rotated_block_provider` -> `rotated`.

worldgen breaking | Changed behavior of `rule_based` block state provider. If a rule yields no results, the following rules will be evaluated.

tag | Added item tag `#furnace_fuel_bottom_takeable`.
