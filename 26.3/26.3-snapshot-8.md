pack breaking obsolete | Data pack format has been increased to `116.0`.

pack breaking obsolete | Resource pack format has been increased to `96.0`.

entity nbt obsolete | Changed `drowned` entity NBT: added fields `angry_at` and `anger_end_time`.

worldgen breaking | Removed feature type `desert_well`. Vanilla now uses the `template` feature type for it.

worldgen | Changed feature type `template`: added optional field `processors`, which is a structure processor ID, list IDs, or tag.

worldgen | Added placement modifier `randomly_selected`, which randomly selects a placement modifier from a list. It has one field `placements` (non-empty list of placement modifiers).

worldgen | Added block predicate `volume_match`, which checks that every block in a volume matches a given block predicate. It has fields `min` (list of 3 ints between -16 and 16), `max` (list of 3 ints between -16 and 16), and `match` (block predicate to test on each position).
