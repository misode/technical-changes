pack breaking obsolete | Data pack format has been increased to `113.0`.

pack breaking obsolete | Resource pack format has been increased to `94.0`.

command breaking | Removed the `gamemode` argument from the `/publish` command. Instead the default game mode of the world should be set using the `/defaultgamemode` command, while player-specific game modes should be set using the `/gamemode` command.

item component | Changed data component `cooking_fuel`:
* `burn_time` and `speed_multiplier` can now also be an inline number provider.

item component | Changed data component `brewing_fuel`:
* `uses` and `speed_multiplier` can now also be an inline number provider.

item component | Changed data component `compostable`:
* `layers` can now also be an inline number provider.

entity nbt | Added entity NBT `invulnerable_time` which makes a mob temporarily invulnerable for a specific number of ticks.

loot | Changed `block_interact` loot type: the `origin` context is now available as the center of the block being interacted with.

worldgen noise breaking | Changed format of the `worldgen/noise` format:
* Renamed `firstOctave` -> `base_octave`.
* Added `base_amplitude`: optional non-negative float, defaults to `1`.
* Added `octave_count`: int between 1 and 32.
* Added `normalize`: optional boolean or `"legacy"`, defaults to `true`.
* Renamed `amplitudes` -> `amplitude_modifiers`: optional list of floats, length must match `octave_count`.

worldgen density | Added density function `pow` with fields `base` and `exponent`.

worldgen density | Added density functions `sqrt`, `log`, `sign` with field `input`.

worldgen density | Added density function `distance_to_point` with fields `point` (list of 3 ints) and `metric` (one of `euclidean`, `euclidean_squared`, `manhattan`, or `chebyshev`).

worldgen density breaking | Removed density function `y_clamped_gradient` and replaced it with `gradient`:
* `axis`: one of `x`, `y`, or `z`.
* `tiling`: one of `clamp_to_edge`, `repeat`, or `mirrored_repeat`.
* `from_coordinate`: int.
* `to_coordinate`: int.
* `from_value`: float.
* `to_value`: float.

worldgen density | Added density function `slice` with fields `axis` (one of `x`, `y`, `z`), `coordinate` (int), and `input` (density function).

worldgen density breaking | Renamed density function `end_islands` -> `end_outer_islands`. No longer computes the density of the main island.

assets breaking | Changed the format of equipment assets:
* Replaced `trim_palette_replacements` with `trim_overrides`: list of objects with fields `when` (object with `material`, `pattern`), `texture`, `palette`.
