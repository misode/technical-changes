pack breaking obsolete | Data pack format has been increased to `109.0`.

pack breaking obsolete | Resource pack format has been increased to `90.0`.

datagen | Removed the `definition` field from the `blocks.json` datagen report.

options | The `white-list` server.properties option is now `true` by default.

item component | Added data component `block_transformer`, which allows items to transform a block into another block on player interaction. It is a list of objects with fields:
* `block_state_provider`: used to provider the state of the transformed block. If it returns no result the next rule in the list will be attempted.
* `sound`: optional sound event to play on interaction.
* `particle`: optional particles to play on interaction.
* `disallowed_faces`: optional list of directions.
* `loot`: optional loot table to drop items on a successful transformation.
* `drop_strategy`: optional field, either `from_middle` (default) or `clicked_face`.
* `transform_type`: optional field, either `single_block` (default) or `copper_chest`.
* `consume_on_use`: optional boolean, whether the item should be consumed.
* `item_damage_per_use`: optional integer, how much damage to take with each use.

loot data | Added `till/rooted_dirt` loot table which drops when rooted dirt is tilled with a hoe.

worldgen | Cave air is no longer generated in nether caves.

worldgen | Added block state provider `copy_properties_provider`, which copies common block properties to the resulting state. It has one field `source_block_state_provider` (block state provider).

worldgen breaking | Renamed feature type `basalt_columns` -> `stepped_column_cluster` and added extra configuration fields:
* `block`: block state provider.
* `can_replace`: block predicate for which blocks to replace.
* `continue_through`: block predicate for which pre-existing blocks to accept as part of a column.
* `cannot_place_on`, block, list of blocks, or block tag.
* `column_count`: int provider between 1 and 150, how many columns to generate
* `cluster_reach`: int provider between 0 and 13, the size of the square to attempt to generate columns in.

worldgen breaking | Renamed feature type `basalt_pillar` -> `single_block_pillar` and added extra configuration fields:
* `block`: block state provider.
* `can_replace`: block predicate for which blocks to replace.
* `direction`: one of `up` or `down`.
* `chance_to_continue`: optional probability between 0 and 1, defaults to `1`.
* `cap_feature`: optional placed feature placed at the end of the pillar.

worldgen breaking | Renamed feature type `glowstone_blob` -> `random_neighbor_spread` and added extra configuration fields:
* `block`: block state provider.
* `accepted_neighbors`: block, list of blocks, or block tag.
* `can_replace`: block predicate for which blocks to replace.
* `attempts`: int provider between 1 and 3000.
* `xz_offset`: int provider between -16 and 16.
* `y_offset`: int provider between -16 and 16.

worldgen | Added feature type `overlay`, which places a set of features in the same location. Opposed to `sequence`, all features are placed regardless of individual placement success. Has one field: `features` (placed feature ID, list of placed feature IDs, or placed feature tag).

worldgen | Added feature type `projected_random_patchy_square`, which generates a square where each block is randomly placed or not placed with its probability based on the distance from the center of the square. It has fields:
* `block`: block state provider.
* `project_through`: block predicate for which blocks are considered "empty" and should be projected through.
* `size`: int provider between 1 and 16 determining the size of the square (measured from center to edge).
* `max_projection_height`: non-negative integer.

worldgen breaking | Renamed feature type `random_offset` -> `offset`. Removed fields `xz_spread`, `y_spread` and replaced them with fields `x`, `y`, `z` (all int providers between -16 and 16).

worldgen | The `spawn_target` field in noise settings can now use any density function, instead of only those defined in `noise_router`.

worldgen | Added block predicate `height_range`, which has two vertical anchor fields: `min_inclusive` and `max_inclusive`.

worldgen | Added vertical anchor option `relative_to_sea_level`, which specifies an option to the sea level.

worldgen breaking | Moved registry `worldgen/configured_carver` to `worldgen/carver`. Carver configuration is now done inline in the root object rather than separated into a `config` field.

worldgen breaking | Changed format of carver type `cave`:
* Added `count`: non-negative int provider.
* Renamed `yScale` -> `room_vertical_radius_multiplier`.
* Added optional `start_vertical_radius_multiplier`: float provider.
* Added `thickness`: non-negative float provider.
* Added optional `weird_thickness_bias`: boolean.
* Removed `replaceable`: carvers will replace any block.
* Removed `lava_level`: fluids are now selected by `aquifer` or `sea_level` configuration.
* Removed `debug_setting`.

worldgen breaking | Changed format of carver type `canyon`:
* Renamed `yScale` -> `shape.y_scale`.
* Removed `replaceable`: carvers will replace any block.
* Removed `lava_level`: fluids are now selected by `aquifer` or `sea_level` configuration.
* Removed `debug_setting`.

worldgen breaking | Removed carver type `nether_cave`. The `cave` carver type can be used instead.

worldgen | Added int provider `very_biased_to_bottom`, with fields `min_inclusive` and `max_inclusive`.

tag | Added block tag `#turns_into_dirt_path`.
