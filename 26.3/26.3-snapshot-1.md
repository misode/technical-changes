pack breaking obsolete | Data pack format has been increased to `108.0`.

pack breaking obsolete | Resource pack format has been increased to `89.0`.

command | When the amount of items passed to the `/give` is above limit, the command will now signal an error instead of just printing an error message and returning `0`.

command text | The `nbt` component in a raw chat message will only be resolved up to 64k times.

command | The `/tick step`, `/tick step stop`, and `/tick sprint stop` commands will now signal an error instead of just printing an error message and returning `0`.

command | The result of `/team join` and `/team leave` subcommands now reflects the exact count of entities that have joined or left.

command slot-source | Slot arguments in the `/item` command can now also be a reference to a slot source file, or an inline slot source (evaluated with the `command_slot_source` loot type).

command breaking | Changed behavior of `/item replace`:
* When there are more destination slots than there are source items, the remaining slots are ignored: `replace [12345] with (ABC) -> [ABC45]`
* When there are fewer destination slots than there are source items, the remaining items are ignored: `replace [123] with (ABCDE) -> [ABC]`

command | `/item ... from entity` now allows targeting multiple entities, the slots sourced from each entity will be concatenated.

command | Added `/item fill` sub-command, which fills each destination slot with a source item, possibly repeating items until every slot is filled: `fill [12345] with (ABC) -> [ABCAB]`.

command | Added `/item override` subcommand, which overrides the contents of slots, possibly clearing remaining slots: `override [12345] with (ABC) -> [ABC__] (where _ represents an empty slot)`.

command slot-source | Added `/execute if|unless slots` sub-command, which counts the number of slots that are present on the block or entity (evaluated with the `command_slot_source` loot type). Syntax:
* `/execute if|unless slots block <pos> <slot source>`
* `/execute if|unless slots entity <targets> <slot source>`

command slot-source | The slot argument in `/execute if|unless items` now also accepts a slot source reference or an inline slot source.

item component | Added data component `provides_pottery_pattern`, which describes the pottery pattern stored on a stack. It is a namespaced ID to a `decorated_pot_pattern`.

item component breaking | Changed data component `pot_decorations`: instead of a list of 4 item IDs, now takes an object with 4 optional fields: `back`, `left`, `right`, `front`.

item component breaking | Changes data component `trim_material` to match new format of material definitions.

trim breaking | Changed format of `trim_material` files:
* Replaced `asset_name` with `palette`: A palette texture ID (referencing a file in `<namespace>:textures/palettes/<path>.png`).
* Removed `override_armor_assets`, overrides are now defined in the RP equipment asset.

instrument | Changed format of `instrument` files:
* Added optional `durability_damage` field (non-negative integer), which is the amount of durability to consume on each use.
* The `use_duration` field can now also be `0` for no cooldown.

slot-source | Slot sources can now be defined as files inside a data pack, within the `slot_source` folder.

slot-source | Changed slot source `contents`: it is no longer restricted to only selecting non-empty slots.

slot-source | Added slot source `reference`, with field `name` (ID of a slot source).

slot-source | Changed slot source `slot_range`: `source` field is now optional, and has a new valid type `container`, which sources slots from a container or inventory provided through loot context.

loot | Added `command_slot_source` loot table context type, which takes parameters: `container`, `origin`, `this_entity`.

worldgen breaking | Moved registry `worldgen/configured_feature` to `worldgen/feature`. Feature configuration is now done inline in the root object rather than separated into a `config` field.

worldgen | Added feature type `end_podium`. It has one field `active`, whether the portal is active.

worldgen | Added tree decorator type `shelf_mushroom`. It has one field `probability` (float between 0 and 1), the probability that any shelf mushrooms will be placed for a given feature.

worldgen | Added foliage placer type `poplar_foliage_placer`, placing leaves in a rhombus shape. It has two fields `height` (int provider between 5 and 16), and `side_hole_chance` (float between 0 and 1).

worldgen | Added trunk placer type `poplar_trunk_placer`, placing logs in a straight shape with branches by the start of the foliage. It has two fields `trunk_height_above_branches` (int provider between 0 and 8), and `branch_amount` (int provider between 1 and 4).

worldgen breaking | Renamed noise settings field `surface_rule` -> `material_rule`.

worldgen | Material rules can now be defined as data pack files in the folder `worldgen/material_rule`.

worldgen | Material conditions can now be defined as data pack files in the folder `worldgen/material_condition`. They can be references within a material rule.

worldgen structure | Added structure placement `dimension_origin`, which places a single instance of the structure at the dimension origin (defined as the `spawn_target` for noise dimensions, otherwise chunk 0-0)

worldgen | Added rule test type `height_match`, checks the Y-level of a block, returning `true` only if it's higher than or equal to `min_inclusive` and lower than or equal to `max_inclusive`.

worldgen | Added rule test type `all_of`, with field `rules` (list of rule tests).

tag | Added block tags `#poplar_logs`, `#wool_stairs`, `#wool_slabs`, `#ores`, `#skulls`, `#blocks_motion`, `#blocks_motion_no_leaves`, `#entities_can_teleport_to`, `#blocks_dolphin_jump`, `#ice_melts_when_destroyed_above`, `#blocks_motion_in_heightmap`, `#blocks_motion_in_heightmap_no_leaves`, `#blocks_lava_fire_spread`, `#blocks_fluid_flow`, `#washed_away_by_fluids`, and `#required_for_poplar_leaf_ambience`.

tag | Added item tags `#poplar_logs`, `#wool_stairs`, `#wool_slabs`, `#mushrooms`, and `#ores`.

tag | Added biome tags for each respective abandoned camp variant: `#has_structure/abandoned_camp_<biome>`.

tag | Added entity type tag `#cannot_be_dismounted_by_item_usage`.

tag | Added damage type tag `#no_wolf_retaliation`.

particle | Added particles `red_poplar_leaves`, `orange_poplar_leaves`, and `yellow_poplar_leaves`.

assets trim breaking | Moved armor trim palette textures from `textures/trim/color_palettes/` -> `textures/palettes/trim/`. The base texture has instead been moved to `textures/palettes/trim_base.png`.

assets trim atlas | Trim material textures are no longer generated into the `trims` atlas with `paletted_permutations`, but rather generated on-demand.
* The base palette id is now specified in a new `palette` mcmeta section field.
* This section has a single field: `base_palette`, the base palette texture ID to remap from.

asset trim breaking | Palette texture locations in the `palette_key` and `permutations` fields have been replaced by palette texture IDs: `<namespace>:<path>` now resolves to `<namespace>:textures/palettes/<path>.png`.

asset trim | Added optional `trim_palette_replacements` field to equipment assets, controlling which trim material palettes should be replaced for this equipment asset (formerly controlled by `override_armor_assets` in the trim material).
